# 🏔️ Projeto Fuji

Landing page imersiva inspirada na estética e na cultura ao redor do Monte Fuji, desenvolvida com foco em design limpo, tipografia elegante e estrutura front-end organizada.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo da página.
* **CSS3:** Estilização avançada, paleta de cores temática e layout responsivo.
* **Git e GitHub:** Versionamento de código e deploy automatizado via GitHub Pages.

---

## 📌 Funcionalidades

* **Design Temático:** Elementos visuais planejados para transmitir uma experiência estética agradável.
* **Responsividade:** Layout adaptado para diferentes tamanhos de tela (desktop e dispositivos móveis).
